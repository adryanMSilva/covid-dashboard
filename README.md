# Dashboard COVID-19

Dashboard desenvolvido em Streamlit utilizando dados públicos de COVID-19 da Our World in Data (OWID).

## Tecnologias

- Python
- Streamlit
- Snowflake
- Pandas
- Plotly
- GitHub

## Funcionalidades

O dashboard apresenta:

- Evolução de novos casos por país;
- Total de óbitos por país;
- Proporção de pessoas vacinadas;
- Relação entre população e total de casos;
- KPIs com informações gerais;
- Filtro interativo por país;
- Aba de dados brutos;
- Exportação dos dados em CSV.

## Fonte dos dados

Our World in Data — COVID-19 Dataset.

## Execução local

```bash
pip install -r requirements.txt
streamlit run main.py
```
